[make.fun bounty "The joke about the demo"](https://make.fun/bounty/the-joke-about-the-demo-20261121-0551).

## The joke

## Run

```sh
python3 main.py
```

Writes the joke to `/output/entry.txt` (UTF-8, 1–280 characters). Set
`ENTRY_OUTPUT_PATH` to write it somewhere else instead.
